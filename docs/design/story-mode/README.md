# ストーリーモード デザイン資料

- `SPEC.md` … デザイントークン、画面一覧、画面ごとの実装メモ（寸法・色・状態・SF Symbols）
- `screens/*.html` … 各画面のモック（番号順が画面フロー）
- `PROMPT.md` … Claude Code に渡す依頼文

## 使い方

1. このフォルダ（`docs/design/story-mode/`）をアプリのリポジトリにそのまま置く
2. Claude Code を起動し、`PROMPT.md` の内容を貼り付ける
3. 1段階終わるごとに差分とプレビューを確認し、「ステップ2に進んで」のように続けて依頼する
