## 画面ごとの実装メモ

### ストーリー入口カード


**配置**

- チャット行（76pt）の間に挿入。カード外周の余白 上下12pt・左右16pt
- 通常行は背景直置き＋区切り線 0.5pt #ECE6EF（アバター右から）。カードだけ面を持たせて区別

**カード**

- 最小高さ 76pt（Dynamic Typeで伸びる）／角丸 18pt
- 内側余白 14 / 14 / 14 / 16pt、要素間 12pt
- 背景 #FFF0F5 → #FFFFFF → #F5F0FF（120°）
- 枠 1pt #F6DCE8／影 0 4 14 rgba(255,117,140,.10)
- カード全体が1つのButton（accessibilityLabel＝タイトル＋説明）

**要素**

- 本アイコン：48pt・角丸14pt、Primary gradient、book.fill 24pt 白
- きらめき：sparkle 16pt #9B82D6（白フチ）をアイコン右上に1つ＋背景に淡い #E9DEFA の大きな sparkle を1つだけ
- タイトル 17 Bold (headline)
- 説明 13 (footnote) #6E6578
- 推しアバター 28pt×最大3、白フチ2pt、9pt重ね（装飾扱い・VoiceOver非読）
- chevron.right 16pt #FF8FA8

**状態**

- 押下：scale 0.98＋背景を約4%暗く（0.12s）
- 推し0人：アバター群を非表示、テキスト幅を拡張
- AXサイズ：アバター群を非表示、2行折り返し可

**SF Symbols**

book.fill / sparkle / chevron.right / person.fill

### 新しい物語（1画面・縦スクロール）


**視線誘導**

- ヒーロー → ①出演する推し → ②物語の設定 → ③参加方法 → 詳細設定（Disclosure）
- 各セクション見出し：28ptのグラデ番号バッジ＋20 Bold。セクション間32pt
- 入力群は白カード（角丸22・枠1pt #ECE6EF）でまとめる

**① 出演する推し**

- 3列Grid（gap 10）、セル角丸18、アバター68pt
- 選択：3ptグラデリング＋右上に選択順バッジ26pt、セル背景 #FFF7FA・枠1.5pt #FFB8C9
- 3人選択時：未選択セルは disabled（opacity .45）
- 外すと後ろの番号が繰り上がる
- カウンター：「n / 3人選択（1〜3人）」0人時は灰色

**② 物語の設定**

- タイトル：必須・30字・高さ52・16pt（iOSのズーム回避）
- 舞台タイル：3列・高さ96、選択は枠2pt #FF7A95＋#FFF0F5
  - SF：graduationcap / house / wand.and.stars
- あらすじ：TextEditor 高さ112・200字
- 雰囲気チップ：高さ44・単一選択
- 恋愛要素あり：Toggle、初期OFF

**③ 参加方法**

- 選択カード2枚（角丸20・radio）
  - 主人公になる：person.fill＋sparkle
  - 物語の一員になる：person.3.fill
- 「一員」選択時のみ『主役の推し』を表示（選択中の推しから1人・pill 48pt）
- 物語内の名前／あなたの役柄：両モード共通

**Disclosure**

- 初期は閉じる（状態一覧参照）。slider.horizontal.3
- 推しごとの役柄：①の役柄を初期値として編集
- 関係：推しのペアごとにSegmented（初対面／友人／ライバル）、初期値は初対面

**固定ボトムバー**

- 白84%＋blur20（.ultraThinMaterial相当）、上0.5pt #ECE6EF
- CTA 56pt。無効時：背景 #ECE6EF・文字 #A69DB0・影なし
- 無効理由をCTA上に1行表示
  - 推し0人：グレー「推しを1人以上選んでください」
  - タイトル空：赤 #D93A55「タイトルを入力してください」＋入力欄を赤枠
- スクロール末尾に150ptの余白を確保

**Play で操作可能**

推し選択・舞台・雰囲気・トグル・参加方法・Disclosure・関係・タイトル入力でCTAの状態が切り替わります

- チャットのような時刻・既読・入力バーは置かない

**選択エリア「あなたはどうする？」**

- 本文の末尾に続く白い大カード（角丸24）＝読み物の一部として配置

- 「または」区切り → 自由入力（TextEditor 104pt・300字・カウンター「n / 300文字」）

**優先関係（誤操作防止）**

- 自由入力に文字がある間は自由入力が優先。選択肢は薄く（.45）無効化し、補足を赤系で表示

- ボトムバーに「選択肢 B｜本文」「自由入力｜本文」のタグ付きで、何で進むかを常に表示
- どちらも無い時：CTA無効（#ECE6EF／#A69DB0）＋「選択肢を選ぶか、行動を入力してください」

**固定ボトムバー**

- 白86%＋blur20、上0.5pt、CTA「この行動で進む」56pt
- 本文末尾に150ptの余白

**章間トランジション（各話の場面3のあと）**

### 非同期処理の状態


**共通ルール**

- 本文（ナレーション・台詞・あなたの行動）は全状態で保持。状態UIは本文の末尾に差し込む
- 処理中は選択エリアを畳み、送信した行動カードを表示。ボトムバーのCTAは disabled（#ECE6EF／#A69DB0）＋lock.fill「〜が終わるまで操作できません」→ 二重送信防止
- 赤 #D93A55 はエラーのアイコン・見出し・「未保存」タグのみ。カード地は白のまま

**1. 次の場面を作成中…**

- 白→#F9F6FF のカード（角丸22）、role=status
- 開いた本＋めくれるページ＋sparkle のイラスト 96×64
- 3つのドット（7pt・#FF7A95）が順に明滅：opacity 1→.25、各0.3sずらし・1.2s周期（Reduce Motion時は静止）
- 「次の場面を作成中…」16 Semibold／補足 13 Secondary

**2. 保存中…**

- 生成された場面3をそのまま表示し、下に小さなピル（36pt）＋ProgressView
- ヘッダーは場面3へ更新済み

**3. 生成エラー**

- 白カード、exclamationmark.circle.fill＋見出し「次の場面を作成できませんでした」赤
- 説明 14 #6E6578（物語と行動は保存済みと明記）
- Primary「再試行」52pt＋arrow.clockwise（同じ行動で再生成）

**4. 保存エラー**

- 生成済みの場面3は表示したまま、枠を破線 #F3C4CD にして右上に「未保存」タグ
- 見出し「場面3を保存できませんでした」＋説明「作り直さずに同じ内容をもう一度保存」
- Primary「再試行」＋下に「生成済みの場面を再保存します」12 Secondary

**5. AI利用上限**

- エラー扱いにせず淡い紫のお知らせカード（#F5F0FF・枠 #E6DDF5）
- hourglass＋「AIの利用上限に達しました」＋「利用枠が戻ってから再開できます。」
- 再試行ボタンなし。ボトムバーも出さない（戻るで一覧へ）

**アクセシビリティ**

- 状態の変化は UIAccessibility.post(.announcement) で読み上げ
- エラーカード表示時は見出しへフォーカス移動
