# 個別チャットのキャラクター・会話設定

チャット右上の設定メニューから「返信の長さ」と「過去・あなたの役柄・心の声」を開く。

- 返信の長さは「短め・ふつう・長め」。既存の会話調整と同じ `speaking_style` の設定行を使うため、どちらから変更しても次の返信に反映される。従来の短め=1、長め=2に加えて、ふつう=3を保存する。
- 「推しの過去」は既存の `roleplay/{userId}/{oshiId}/profile/background` をそのまま利用する。既存データの移行は不要。シチュエーション・追加キャラ設定のプレミアム／無料お試し条件を適用する。過去だけを保存した場合もお試しを開始できる。
- 「この推しと話すあなた」は同じ推しのスコープの `userPersona` に保存する。名前・年齢・立場・性格・関係・過去はすべて任意。公開プロフィールは変更しない。返信の長さ・相手役・心の声は無料でも利用できる。
- 相手役の有効な設定を変更したときは `personaUpdatedAt` を更新する。表示用の履歴は残し、生成・記憶抽出では変更前の会話と古い役柄を除く。要約と抽出位置を同時に更新し、遅れて完了した古い抽出結果はリビジョンで拒否する。記憶の保存上限は従来通りで、現在の役柄を優先する。
- 心の声は返信と同時に生成する短い物語上の本音。`innerThought` としてメッセージに保存し、タップ時に追加生成しない。セリフ・既読・親密度とは独立して開閉する。非対応の過去メッセージにはボタンを出さない。表示がロックされた返信では心の声も表示しない。
- 心の声をオフにすると以降の生成を停止する。過去に保存した心の声は読み返せる。会話要約や記憶抽出に心の声は渡さない。
- 設定の保存はFirebaseの完了確認後に画面を閉じる。変更した項目の競合を検出し、失敗時には入力を残してエラーを表示する。

検証は `CharacterConversationFeaturesTests`（データ互換性・設定優先順位・役柄切替・保存処理・生成履歴）と `CharacterConversationFeatureVisualTests`（標準／大きな文字、ライト／ダーク）を使用する。既存のロールプレイ、会話調整、記憶、プレミアム機能のテストも回帰確認する。
